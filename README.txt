LEXEME Static Website

شروع سایت: index.html
صفحه اصلی: home.html
آرشیو شماره‌ها: issues.html
صفحات شماره‌ها: summer-2025.html, autumn-2025.html, winter-2026.html

ساختار سایت کاملاً استاتیک است و از HTML، CSS، JavaScript و تصاویر محلی استفاده می‌کند.
برای اجرا، index.html را باز کنید. برای تست حرفه‌ای‌تر می‌توانید داخل پوشه این دستور را اجرا کنید:
python -m http.server 8000
سپس http://localhost:8000 را باز کنید.

انیمیشن‌ها با CSS و فایل assets/js/main.js پیاده‌سازی شده‌اند.
پوشه assets/original-media شامل تمام تصاویر و فایل‌های رسانه‌ای استخراج‌شده از MHTMLهای ارسالی است.
کدهای اضافی Canva و افزونه مرورگر حذف شده‌اند.

Original Canva runtime scripts and font files were not embedded in the MHTML exports, so the responsive layout and animations were rebuilt with local HTML/CSS/JS.
